Please report security vulnerabilities privately to the maintainers of the BackupPlus repository or distribution from which you obtained the plugin. Do not publish vulnerability details in a public issue before a fix is available.

Include as much of the following information as possible:

* Type of issue (for example, SQL injection or cross-site scripting)
* Affected version(s)
* Impact and a description of how the issue could be exploited
* Step-by-step instructions to reproduce the issue
* The location of the affected code
* Any special configuration required to reproduce the issue
* Relevant log files, if available
* Proof-of-concept code, if available

Please allow the maintainers reasonable time to investigate and prepare a fix before disclosing the issue publicly.
