BackupPlus for WordPress

BackupPlus backs up and restores WordPress websites. To move a site, create a backup and restore it on the destination. It is a modified GPLv3 fork of UpdraftPlus, with changes through 2026, and retains the original copyright and license notices in the source files.

Backups can be run manually or on a schedule. Files and the database can use separate schedules, and existing BackupPlus backup sets can be restored.
